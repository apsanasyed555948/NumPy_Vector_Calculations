# NumPy Vector Calculations

## Project Description
This project demonstrates vector calculations, matrix operations, linear algebra transformations, dot products, and multidimensional array operations using Python NumPy.

## Technologies Used
- Python
- NumPy

## Features
1. Create NumPy arrays.
2. Perform vector addition, subtraction, multiplication, and division.
3. Calculate dot products.
4. Create two-dimensional arrays.
5. Perform matrix addition and multiplication.
6. Calculate transpose, determinant, and inverse.
7. Create and analyze multidimensional arrays.
8. Calculate mean, maximum, minimum, and sum.

## Installation

Install NumPy using:

```bash
py -m pip install numpy
```

## How to Run

```bash
py main.py
```

## Project Output
The program displays the results of vector calculations, matrix operations, linear algebra transformations, multidimensional arrays, and statistical calculations.

## Conclusion
This project demonstrates how NumPy simplifies numerical computing and makes mathematical and array operations easier in Python.
